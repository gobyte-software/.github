# GoByte Software

Custom websites, web apps and mobile apps for businesses and founders. Built with Laravel and Go, with cross-platform mobile on top when a project needs it.

We're a small software house. You talk to the developer who writes the code.

## What we build

- **Business websites that do a job.** Practice sites with online booking for doctors and dentists, hotel sites that take direct bookings and sync with Airbnb and Booking.com, restaurant sites with reservations. Fast, bilingual where needed, built for local search.
- **SaaS and web applications.** Multi-tenant platforms with accounts, billing and admin, and the internal tools that replace the spreadsheet everyone is afraid to touch.
- **MVPs for startups.** Fixed scope, 4 to 8 weeks, a working demo every week, and the code is yours from the first commit.
- **Mobile apps.** One codebase for iOS and Android, sharing a backend with the web product.

## How we work

- Laravel when the problem is product and speed of change. Go when it's throughput and reliability. Often both in the same system.
- Everything lives in your accounts: repository, hosting, domains. Nothing is held hostage.
- Weekly demos on a real URL, scope changes discussed in the open.
